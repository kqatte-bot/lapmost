# ЛапМост — промо-сайт

Статический сайт Телеграм-бота ЛапМост. Без сборки и зависимостей: `index.html` + папка `assets/`.

## Публикация на GitHub Pages
1. Settings → Pages → Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)`.
2. Через минуту сайт будет на `https://<логин>.github.io/<репозиторий>/`.
3. Свой домен: Settings → Pages → Custom domain (добавится файл `CNAME`), у регистратора CNAME-запись на `<логин>.github.io`.
